GB data layers used to run the model:

ADB estimated arrival year (arrival_GB3011)
Gravimetric soil water content (eusoil_GB3011)
Non-woodland proportion of ash (nonwoodp_GB3011)
Mean annual precipitation (mm) difference from minimum (precipp_GB3011)
Ash density map (treeDensity_GB)
EAB initial arrival locations used in realisations (SampleEntry)
Probability of EAB intial arrival (InclusionProbGB)
Owners_GB file for behaviorual model, still read in the code, but not actually used
